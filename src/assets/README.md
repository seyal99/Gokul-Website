Assets folder for website content.

Suggested usage:
- `src/assets/images/` for photos, backgrounds, and project screenshots
- `src/assets/icons/` for svg/png icons and logos
- `src/assets/docs/` for PDFs (resume, certificates, etc.)

Import examples in Vue:
- `import profilePhoto from "@/assets/images/profile.jpg"`
- `import resumePdf from "@/assets/docs/resume.pdf"`
